# 轻量共享登录契约

用户已确认没有外部身份系统，只需四个平台共用账号；本期不部署 Keycloak，不实现独立 OAuth/OIDC 身份服务器。

Go/Gin 的 identity 模块维护账号、bcrypt 密码散列、部门、平台能力及 PostgreSQL 服务端会话。无公开注册。管理命令从标准输入读取私密账号配置，密码限制为 12—72 字节，禁止静默截断。能力列表可以为空，默认不授予任何平台权限。

| 接口 | 约束 |
| --- | --- |
| POST /auth/login | JSON；Origin 必须匹配 APP_ORIGIN；每 IP 每分钟最多 12 次；账号及密码错误使用相同提示 |
| GET /api/v1/me | 返回明确 DTO：用户、部门、平台能力和内存中使用的 CSRF 值；不返回密码散列或会话令牌 |
| GET /api/v1/platforms/{platform}/access | 服务端检查 exchange/governance/assets/security 能力，不能通过前端改状态绕过 |
| POST /auth/logout | 同时验证 Origin、会话和 X-CSRF-Token；删除当前会话，四平台后续请求失效 |

会话为随机 32 字节的不透明标识，数据库只保存 SHA-256；Cookie 使用 Secure、HttpOnly、SameSite=Strict、Path=/，不设置共享父域。绝对期限 8 小时，空闲期限 30 分钟。每请求查询账号有效状态和当前能力，不缓存权限。CSRF 值通过持久化服务器密钥与当前会话 HMAC 派生，前端只放临时内存。

同一入口下四个平台复用当前会话；没有某平台权限时，该平台后端拒绝请求。数据授权由后续 exchange 模块校验，本批平台访问探针不等于数据查询已授权。

本地 HTTPS 使用 .local/certs 下的独立自签证书，验证脚本显式信任该证书；不使用跳过校验参数。浏览器使用时需信任这张本地证书。认证数据库不可用返回 503，不降级放行。未实现的业务接口返回 404，不能以空列表或成功状态代替。

## 组织和人员管理（2026-11-04）

组织单位保存在 organization_units；根节点为组织，部门支持多级。历史 department_id 原样迁入，未核实单位代码留空。账号 display_name 为人员姓名，version 用于维护冲突检测。管理员通过组织/人员入口和账号菜单直达管理，普通账号无管理权限。

账号修订在同一事务替换平台和角色并清除会话；调岗撤销原岗位范围和加工授权，保留原部门业务资源与审批历史。禁止当前管理员自禁用、自调岗或自降权，并保留有效管理员。组织层级创建后固定，停用前检查在用人员和子单位。维护原因、变更前后内容进入 identity_change_records，密码和会话令牌不进入该表。

目录提供单位从所属组织读取；自动编码采用经主管配置的字典模板、事务内流水号及全局编码预留，生成结果仍按字典规则校验。未配置模板或正式单位代码时明确提示，不自动推断国家编码规范。
