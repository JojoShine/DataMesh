- 平台切换为紧凑按钮，显示当前平台、用途与权限范围并可跳转（后续相关测试通过）。
- 资产分类菜单能进入总览、分类浏览和独立反馈，保留消费权限（后续相关测试通过）。

- 告警在当前窗口内处理，不叠加弹窗。
