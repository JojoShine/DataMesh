# 共享交换数据服务验证

## 实现范围

- 共享交换新增“数据服务”，从已发布 Doris 治理成果登记不可覆盖的查询接口；修改通过复制生成新资源，重新挂载、审批及授权。
- 单成果参数化 SELECT，支持字段投影、AND 比较条件、单字段排序。实际 SQL 由校验后的结构生成，表名由服务绑定；参数使用驱动绑定并按字段类型转换。
- 固定成果或跟随同一数据流最新已发布成果。字段契约改变时拒绝，分页游标绑定实际成果、调用者、授权、字段及参数。
- 复用目录挂载与使用授权、敏感字段脱敏、调用审计。外部凭据仅存 SHA-256 哈希，绑定用户、部门、接口、原授权及期限，创建后只显示一次。
- 数据库迁移 34 新增 data_service_keys；不更改现有业务记录。

## 已执行验证

- `go test ./internal/modules/workflow -run '^(TestAPI|TestDataService)'`：SQL 边界、禁止敏感字段筛选/排序、字段/参数校验、布尔/日期/UTC 时间和十进制精度通过。
- `python3 scripts/test_identity.py --run '^TestGovernanceDataflowExecution$/DataServiceDelivery'`：隔离 PostgreSQL 迁移 1–34；使用真实 Doris 运行治理、发布成果、预览/登记服务、签发凭据、查询；通过字段范围和脱敏、非法参数、伪造游标、跨接口凭据、共享暂停、来源下架、凭据撤销、授权撤销及新授权不能复活旧凭据检查。另运行同一数据流生成第二份成果，验证 latest 返回新成果而 snapshot 保持原成果。
- 前端 data-services、directory、governance-dialog-actions 三组共 27 项通过。覆盖复制后的重新校验、修改查询使预览失效、凭据仅本次显示及撤销后清空。
- `npm --prefix web run build`：类型检查及生产构建通过；保留项目已有大包体积提示。
- 浏览器验证使用隔离假数据驱动实际组件，不代表线上业务数据验证；检查 1920×1080 和 540×960。弹窗内部滚动，关闭/校验/登记固定在右下角，窄屏无页面横向溢出。临时预览入口已删除。
- 部署前备份恢复验证通过，53 张表记录数一致。

## 使用边界

当前提供单成果查询，不开放调用方 SQL、跨表查询或任意函数。关联、清洗、聚合应先在数据治理完成。授权沿用现有资源、字段、用途和期限模型，不声称已提供逐用户行级策略。限流与并发限制按单服务实例执行。

## 部署

发布版本：`data-services-20261030-101500`。数据库版本 34，干净状态；43 项 HTTPS 接口/页面检查及 14 项静态资源一致性核验通过。既有业务表记录数与受保护内容哈希保持一致，备份已验证可恢复，旧镜像已保留。未在生产自动创建接口、挂载或授予任何账号新的访问权限。
