# 可共享资产消费流程验证

## 本次范围

资产菜单：资产发现、我的申请、我的资产。暂不增加内部资产台账，不自动共享治理成果或私人 CSV。治理成果核验/发布与共享目录审核保持独立，历史发布管理地址仍兼容。

资产发现使用已发布、已审核且存在有效共享挂载的目录，包含原始数据、治理成果、库表、文件和 API。使用者可查阅共享字段、已有治理内容、质量结论和资源信息更新时间。该更新时间不是源数据实时更新时间；无质量证据时明确显示未提供结论。

资产只读入口：GET /api/v1/assets/directories、/applications、/grants。本人列表在服务端按 owner_id 限定，包括管理员。申请提交/撤回/补正、交付、个人 API 凭据复用现有服务，允许资产平台账号访问；目录维护、资源登记、审批与撤权仍要求共享交换权限和原有资源授权。

## 实际验证

- 隔离真实 PostgreSQL：TestAssetConsumerJourney，通过。资产单平台账号可发现/提交/补正；不能读取交换管理、批准或撤权；同部门提供者的本人列表不出现使用者记录；审批生成同一份授权；暂停共享后不可使用、不可继续发现。
- 未归档的原始对象经授权后仍返回 RAW_NOT_ARCHIVED，不绕过实际数据就绪检查。
- 隔离真实 PostgreSQL + Doris：TestGovernanceDataflowExecution/DataServiceDelivery，通过。消费账号临时限制为仅资产平台，验证实际治理成果查询、快照/最新成果、调用凭据、原授权约束和失效控制；结束后恢复隔离账号权限。
- 前端：资产交互 4 项、目录 23 项、数据服务 2 项、导航 7 项、指南 2 项通过。包括门户成果链接自动定位、单层详情/申请返回、只读个人菜单、共享暂停禁用使用。
