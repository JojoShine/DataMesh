# 业务用途映射与直接调度合并部署

## 变更

- 数据建模选择业务用途，复用原 `data_layer` 合约映射 DWD / DIM / DWS / ADS；ODS 仍由接入确定。
- 新模型没有隐式 DWD 默认值；逻辑、物理模型确认用途，概念模型允许暂不确定。
- 绑定输出模型后只展示继承用途；推导输出选择用途，自动生成模型继承本次成果分层。
- 已分类模型重新绑定会清除重复的输出分层。历史未标注模型保留数据流原有分层；两者都没有时明确说明 DWD 兼容规则。
- 模型加载期间禁止切换结果结构，避免把尚未读取的 ADS / DWS 误写成默认 DWD。
- 分层筛选有明确标签，持续运行启动前读取模型分层。
- 合并此前数据流固定批/流方式、直接调度及可选工作流的改动；数据库迁移 32。
