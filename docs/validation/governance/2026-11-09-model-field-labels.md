# 模型中文字段名称修复

根因：业务来源和治理运行已保存中文字段名称，但业务初始化构建模型时只复制了技术字段与类型，遗漏description；治理扩展初始化的实体模型也有同样遗漏。页面在缺少名称时正确显示占位文字，问题来自初始化信息丢失。

修复：两个初始化脚本均保留来源字段说明。历史模型在字段表及实体关系中读取同一模型版本已登记成果的字段名称；尚无成果的实体模型按明确来源映射读取当前有权查看且契约版本匹配的资源名称。名称来源有冲突时保留待补充，不按英文名进行跨资源猜测。模型已有字段说明优先。新增查询为只读，不改变定义、引用或执行指纹。

验证：13项相关前端检查、类型检查及生产构建通过；OpenAPI及19项契约检查通过；隔离PostgreSQL与真实Doris扩展检查通过，58.822秒，包含实际输出名称查询及不可变模型未被改写的检查。初始化模块导入与语法检查通过。

本机已部署model-field-labels-20261109-165050；部署前另行备份，实际二进制和页面摘要一致，原业务记录摘要保持。正式接口核对六个业务结果模型、人口与法人两个实体模型，共8个模型55个字段，中文名称全部可解析，模型版本保持。
