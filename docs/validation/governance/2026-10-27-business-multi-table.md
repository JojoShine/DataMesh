# 业务步骤多表关联验证 · 2026-10-27

## 实现

- 在“选数据”区域增加“添加关联表”，逐张选择来源及字段；区分主表和关联表，并在“定规则”中展示对应的关联步骤。
- 添加关联表时，将现有处理结果作为主输入，在结果输出前增加独立来源及关联；默认保留已有全部记录，用户明确选择双方对应字段和关联方式。
- 字段沿用现有初始化与唯一命名规则，保留已有输出映射和质量出口。连续添加第三张表时接在原关联结果之后，避免新字段被已有映射遗漏。
- 业务模式可继续插入、移除整理步骤；移除关联表或关联步骤时，同时删除其专属来源，自动恢复主处理链并提示核对后续字段。
- 结构识别只接受一条主处理路径及独立的关联来源。共享输入、右侧预处理分支、断线、循环和不合格分支继续进入高级编排，保留原关系。
- 复用现有来源、关联、字段推断和保存接口，无后端、授权、数据结构或数据库迁移变更；更新 Markdown 指南与业务视图规范。
