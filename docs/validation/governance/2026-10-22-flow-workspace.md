# 数据流独立工作页验证记录

2026-10-22，将数据流设计从业务 dialog 调整为独立页面。用户明确要求数据流使用非 dialog 布局；其他治理页面的单层 dialog 约定不变。

## 界面和功能

- 左侧可搜索、分页的数据流列表；右侧展示设计、前置字段核对、版本影响、实际运行和代码样本结果。进入后自动展开第一个可用数据流，已有定义及运行深链接继续有效。
- 列表、节点配置可分别收起，点选节点重新展开配置。保留现有画布拖动、连线、撤销重做、布局保存和代码编辑功能。
- 工作区命令集中到底部右侧；节点配置和结果中的命令继续通过共享操作区呈现。独立工作页不创建业务 Modal。
- 切换时可继续编辑、明确放弃或先保存后切换；保存失败保留当前修订，现有定义、权限和不可变版本契约不变。
- 用途、前后关系、使用指南和责任信息保留，可展开阅读；教学虚线引导仍使用独立单层教学 dialog。
- 1440×1000、1920×1080、540×960 合成数据页面核验。窄屏改为上下结构并允许页面滚动，修复列表记录区被压缩的问题；底栏靠右换行，配置区保留内部滚动。
