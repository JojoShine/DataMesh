# 治理外层交互修正（2026-10-23）

## 范围与决策

按用户确认的方向修正导航、空间切换和看板。本轮不调整内部业务表单、数据流配置、成果发布流程或正式业务对象名称。

- 空间作为当前工作范围选择器；切换保留功能路径，清除原空间对象参数，继续受未保存修改保护。

- 无治理角色时不自动请求空间列表；帮助默认收起，子菜单面包屑保留业务分类层。
- 无数据库迁移，不更改权限及现有业务记录。
