# 资产证据与使用反馈衔接验证

## 范围

- 资产详情按共享条件、字段质量与更新证据、使用反馈分区；仅提供审核映射内的字段口径和责任人，不返回 SQL、凭据、物理存储配置或原始运行定义。
- 固定成果生成时间、上游最近运行状态、成果文件归档时间分开显示。API 数据服务按既有交付逻辑解析实际来源。没有可靠数据截止时间时显示未知，不用资源信息修改时间替代。
- 输出模型校验和业务检查分开；实际输出、隔离数量来自运行证据，不将成功生成当作所有质量要求通过。
- 使用者可从发现或本人授权提交质量、时效、口径和访问反馈；历史授权失效后仍可反馈访问问题，反馈保留原资源版本。
- 治理质量管理新增“使用反馈”页签，按部门及空间受理；本人反馈列表严格限定本人，包括管理员。回复与事件为公开信息，内部整改笔记不对外展示。
- 有原运行访问权限的人员可新建或复用整改。同一运行不重复建单；关联整改后必须先完成原有真实复测关闭流程，才能完成反馈。反馈不自动启动治理或发布。

## 验证

- 真实隔离 PostgreSQL 迁移至 35，TestAssetConsumerJourney 通过：受控详情、未知截止时间、错误版本、个人与跨部门隔离、字段限制、公开回复历史、过期版本冲突、无运行禁止建立整改、共享暂停后历史授权反馈。
- TestGovernanceDataflowExecution/AssetEvidenceFeedback 通过：实际 Doris 成果的输出与隔离数量、模型校验与业务检查证据、关联整改、同一运行复用、无复测禁止关闭及禁止完成反馈、内部整改笔记不泄漏。
- 46 个相关前端用例通过（资产、目录、数据服务、质量流程）；包含单层详情、未知时效、反馈页隐藏无关申请按钮、使用者不能打开内部整改单。
- 导航 7 项、指南 2 项通过。指南首次运行遇到资源争用超时，独立重跑 2 项通过。
- TypeScript 和生产构建通过，保留既有大包体积提示。
- 使用实际组件和示例数据完成 1920×1080 与 540×1000 浏览器检查：字段表内部横向滚动，内容纵向滚动，反馈表单与固定底部操作，治理公开回复和历史。临时预览文件已删除，未写入主库。
- 首轮并行负载导致隔离登录及前端用例超时；分开执行后上述集成与 46 个前端用例通过，未修改权限或业务断言规避失败。

## 边界

API 使用时反馈未携带真实交付快照凭证，因此不会擅自把问题关联到当前最新来源运行；按接口提供部门受理后核实。无治理运行的口径、访问问题可核实后直接公开回复。没有在正式库创建测试反馈、申请或调用凭据。
