# 数据流执行方式与直接调度验证

## 实现范围

- 数据流版本固定为 batch 或 continuous；新建默认 batch，修订省略方式时继承原版本。选择其他方式会产生新版本，已有版本不被覆盖。
- 批量数据流可立即运行或直接创建定时计划，不需要工作流包装。
- 流式数据流显示持续运行管理，批量运行、周期调度及工作流有界子任务入口会拒绝流式版本。
- 数据流内的定时计划和中央调度页使用同一套数据及接口；工作流保留独立定时入口。
- migration 32 只增加版本模式和调度目标类型，不修改历史定义/运行 JSON。历史已发布工作流仍引用曾流式运行版本时，迁移在变更前明确阻止。
