# 数据治理可用性复核与使用指引

本轮遵照用户要求：直接实现后验证，不采用红绿测试，不使用子代理；补齐后部署主环境。数据库保持 Schema 24。

## 使用入口

打开数据治理的“治理总览”，默认展开“使用指南 · 从接入到共享”。首次使用按以下顺序推进：

1. 共享交换接入来源、登记资源并办理加工授权。
2. 发布治理基础中的主题域、标准和输出模型。
3. 在元数据核对结构，按需配置文件契约、执行剖析。
4. 建立“来源 → 处理 → 质量 → 输出”的最小数据流，发布并手动运行。
5. 查看运行与成果，再配置工作流、日历调度及告警。
6. 由有权资产提供方核验发布；下游使用仍遵守目录挂接、审批和授权流程。

各页面及关键操作弹窗内提供25个主题的可折叠使用指南，包含用途、前置条件、操作步骤、示例或边界、结果去向；相关入口在新标签页打开，保留当前填写内容。指南直接使用当前已有功能，不要求用户从接口猜测操作流程。

## 本轮补齐与修复

- 修复调度参数未注册到提交表单导致覆盖值丢失；切换工作流版本会清除旧覆盖值。
- 修改cron或时区后撤下旧触发预览；新建调度清空上次内容，保存操作固定于Dialog标题区。
- 暂停/启用调度移至管理Dialog，展示固定参数及状态，使用服务端返回的新版本继续操作。
- 生命周期从成果行直接进入对应数据流保留策略或原成果迁移；用可搜索名称的数据流选择器、可翻页成果选择器替代手填编号。
- 模型、数据流、工作流详情显示完整定义编号；修正引用影响中“编排接入后补齐”的过时提示。
- 发布管理恢复已有的历史数据集登记入口，说明它与自动数据流成果的差异及前置条件。
- 旧质量规则发布改为单层Dialog核对后确认；成果质量检查先打开结果Dialog，再由弹窗内执行。
- 帮助以内嵌展开区域呈现，不另开帮助弹窗。创建、配置、详情、预检及审批采用居中Dialog，详情切换复用当前层。
