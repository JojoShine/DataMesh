# 治理补齐：统一元数据与数据剖析

后续代码进展及当前边界见[治理现状与补齐记录](2026-10-21-completion.md)。下文保留原阶段时点的记录。

开发阶段验证记录，尚未部署，不代表整轮治理闭环完成。

已补充：

- 元数据统一列出采集对象、普通挂载库表、Excel 导入表、治理成果及文件/API 契约。数据库读取真实结构；其他资源明确标为登记契约，不读取文件内容或调用 API。返回内容不包含资源私钥、凭据及 API 测试参数。
- 数据库表与 Excel 导入表支持持久剖析任务。可选择字段、采样（默认前1,000行，最多10,000行）或全量；采用现有行数、字节及连接白名单边界，任务最长10分钟。采样不是随机样本，报告明确覆盖行数与来源总行数，不能当作全库统计。
- 提供字段空值数、不同值数、重复值行数、极值与前10项频率；数值按数值比较与分组，保留大整数和精确小数。长展示值截断并标识；最多20项异常仅包含观察行序号、字段和原因，不展示记录值。
- 敏感字段仅显示空值数量，隐藏不同值、极值、频率与重复值样例。执行日志仅保存阶段、代码与计数。
- 职责与加工授权在创建、执行期间和报告读取时检查；取消、超时、授权变化均不能生成成功报告。临时数据位于独立会话事务，结束即回滚清理。
- 队列可跨请求和服务实例存续，活跃租约不被新实例夺取。丢失读取快照的运行标记中断；重新观察创建新运行并关联旧记录，不伪装成旧快照恢复。
- 元数据页内查看剖析历史、报告、日志与取消操作，没有新增嵌套弹窗，沿用固定字号规范。
