## 本次完成范围

- 共享交换增加「资源目录」「编目与挂载」「审核工作台」，原有数据源、接入、原始资源等入口保留。
- 数据安全增加资源权限配置，区分管理、加工、审批和数据使用。管理员身份本身不授予取数权限。
- 目录支持草稿、修订、提交、部门审核、主管审核和撤回；展示已发布版本，避免未审核修订覆盖公开内容。
- 原始数据与治理成果均可挂载到目录，复用现有资源，不重复采集。挂载经过字段映射、可用性校验、审核后才能启用，支持暂停和卸载。
- 使用申请支持材料补充、重新提交、审批与授权。授权取数校验申请人、部门、字段、有效期及目录和挂载快照，禁止自批。
- 加工授权与使用授权分开；加工授权撤销后，阻止新的治理操作和治理成果交付，原始资源的独立使用授权按自身状态校验。
- 门户只展示经目录审核允许公开、且存在有效挂载的摘要；名称、说明等采用审核后的目录内容。
- 前端沿用现有蓝色 Ant Design 规范，本次未重新设计门户和登录页。

## 查看入口

登录后进入共享交换，依次查看资源目录、编目与挂载、审核工作台；在数据安全中查看资源权限。操作入口依据当前账号的角色、部门和资源职责显示。

本地验证后有两项已挂载资源，分别对应原始数据和治理成果。目录、挂载和审批均使用真实接口；演示账号配置保留在被 Git 忽略的本地文件中。

## 当前边界

1. 本地启用测试目录字典及 `TEST-` 编码。当前一份已验证字典是测试字典，尚未导入正式编码字典和完整标准条款映射，不能据此声称完全符合国家标准。
2. 实际治理执行仍采用现有 PostgreSQL `public.customers` 到 Doris 的固定模板，未实现任意库表、多源融合、文件/API 挂载或通用行级权限。
3. 共享 Flink 模板尚无按个人加工授权绑定作业的机制。撤销加工授权会阻断新治理操作及成果交付，但不会自动停止某个人对应的既有共享作业。
4. 原始归档仍是有边界的归档核对流程，不等同于持续 CDC 全量自动补偿。
5. 为保留本地数据，未删除并重建空 Docker 数据卷验证完整首次启动；已验证真实读权限、缺表行为及脚本语法。以后更新中间件环境变量应通过 Compose 重建容器。
6. 本次未作全平台性能、法规时限引擎或灾备恢复验收，不代表一期全部生产验收完成。
