## 验证边界

当前没有国产库联调实例，尚未验证目标版本、兼容模式、国密认证。SQL Server、MongoDB 也尚未完成真实实例联调。HBase 当前使用 REST 网关，不接入 Kerberos；Redis 当前不支持 Cluster 或模块自定义类型。新增类型只读，暂不提供 CDC、目标写入、模型建表；单份来源最多10,000条、20 MiB、100字段，超限失败。文档型来源按完整 JSON 列授权；实时读取不保证跨记录事务快照。
