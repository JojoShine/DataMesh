## 实现边界与未验证项

- `.xlsx` 导入实际数据，不导入目录字段定义；旧 `.xls` 不支持。导入上限 20 MiB / 100 列 / 5 万行，文件上限 50 MiB，尚未做最大容量吞吐压测。
- 数据库直接查询目前支持 PostgreSQL/MySQL；Oracle 保留既有 CDC 链路。直接查询需要可识别主键，不是跨页数据库快照。
- API 支持查询 GET/POST 和 JSON 标量字段映射，须先配置允许源站及解析地址；本地 API 限流为单实例内存计数，重启会重置。
- Office 结构/外部链接检查不等同于病毒扫描；PDF 活动内容检查为基础检查，不承诺深度文档安全检测。
- 过期未确认上传在下次上传时清理；未新增后台定时清理服务。确认采用同步校验及原子事务，失败可重试，超时可查询批次状态。
- 本次未执行最大容量、进程强杀、所有故障注入或完整响应式视觉验收。浏览器因本地 HTTPS 证书不受信任拒绝打开，未绕过证书校验；界面验证来自自动化组件测试。
- 前端仍有现存大包体积提示，本次未扩展到代码分包重构。
