# 治理入口与成果闭环 Implementation Plan

**Goal:** 按四项用户要求补齐使用引导、真实模型及单表成果归属。
**Architecture:** 修改既有菜单与首页；结果生成真实模型草稿；成果保存来源证据并在原目录提供独立治理资源，沿用申请与审核链路。
**Tech Stack:** React / TypeScript / Ant Design / Go / PostgreSQL。
**Spec:** docs/superpowers/specs/2026-10-26-governance-completion-design.md

## Tasks

- [x] 菜单图标、门户与治理首页流程和常用工作流入口；验证角色/空间链接及响应式布局。
- [x] 先复现模型仅在内存存在，再持久化真实草稿、兼容历史完整运行、更新结果链接；验证普通数据流和工作流子任务。
- [x] 增加可信来源与处理摘要、原部门归属、原目录/新目录选择；保留质量、权限和历史证据检查。
- [x] 原目录显示独立资源版本，申请精确使用对应资源字段和快照；安全迁移挂载唯一性约束，验证原始资源不受影响。
- [x] 运行针对性测试、隔离数据库集成测试、前端检查与构建，复核改动。

沿用当前未跟踪工作区，不提交、不重置用户文件；按用户已给定的明确需求直接实现，独立领域并行，最终统一验证。
