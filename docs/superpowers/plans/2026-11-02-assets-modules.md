架构：沿用 App 菜单分组、Assets 发现与详情、AssetFeedbackList。保留原路由和权限，不改后台契约、不新增依赖。

- [x] AssetWorkspace.tsx 提供总览（接口返回总数，失败不记作零）、分类浏览（基础/主题/部门）、反馈入口。Assets 支持可信证据模式与 URL 分类。

行业依据（2026-11-02 核对）：
- https://learn.microsoft.com/en-us/purview/unified-catalog ：业务域、数据产品、业务术语、健康管理与自助访问。
- https://docs.databricks.com/aws/en/data-governance ：发现、权限、血缘、敏感分类、质量与共享。

本轮补齐消费侧已有后台支持的能力。质量与更新展示运行证据，不生成质量分数或实时性承诺；已授权总数不等于有效授权数。

后台能力补充已在 `2026-11-02-asset-products.md` 中实施：
1. 数据产品：组合固定共享版本、负责人、业务域/术语、草稿与发布版分离、独立审核。
2. 契约与服务承诺：共享与字段兼容性、成果生成时效、运行隔离比例主动检查；个人历史及去重站内违约提醒。
3. 资产运营：本人成功交付的真实审计统计。成本和业务价值缺少计量来源，返回null，不推算收益。
4. 认证与生命周期：人工限期认证、到期状态、弃用及替代产品、停用；不改变原资源授权。
5. 业务语义与安全关联：复用已发布治理定义的名称和说明，产品关联到共享资源及既有来源处理说明，不公开内部SQL、凭据或未共享节点。

完整字段级血缘图、费用核算和业务收益量化不在本轮已实现范围，仍需独立的数据来源及访问边界设计。
