# 数据服务发布 Implementation Plan

**Goal:** 在共享交换把 Doris 治理成果定义为参数化查询 API，复用目录审核、授权和审计，并提供外部调用凭据。
**Architecture:** 复用 api_resource 与现有交付授权，新增治理查询适配器和数据服务管理页。查询只允许平台校验后的单成果只读 SELECT，表名由平台绑定，参数绑定而非拼接。已发布版本不可覆盖；修改生成新的资源版本，须重新关联目录并审核，历史授权不自动扩大。
**Tech Stack:** Go/Gin/GORM、Doris、React/Ant Design。
**Spec:** 本会话用户批准的“选择成果→定义查询→配置接口→校验发布→申请授权→调用审计”方案。

## Constraints
- 不使用子代理，不采用红绿测试流程；实现后进行针对性验证。
- 保留原有外部 API 接入、库表及文件交付；不改既有授权语义。
- 提供固定成果和同一数据流兼容最新已发布成果选择；未核验、未发布、权限失效时拒绝调用。
- 不接收调用方 SQL；禁止跨表、写入、多语句、注释、任意函数和未声明参数。
- 外部凭据只存哈希，绑定账号、接口及到期时间；每次调用复查当前账号与授权。
