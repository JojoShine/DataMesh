# 数据源扩展实施计划

目标：按已确认的14类数据源建立真实只读接入及下游联动。

架构：复用 Go 平台业务流程，新增受认证的只读 source-reader 服务承载 JDBC 与文档源协议，避免把新类型套入已有 CDC/事务写入分支。

技术：现有 Go/React/Ant Design，Java21标准HTTP服务、JDBC、MongoDB官方客户端、Jackson；Redis RESP、ES/HBase REST。厂商驱动通过管理员只读挂载安装。

- [x] source-reader：驱动状态、连接检查、对象、结构、有界全量读取；凭据不进日志。
- [x] Go 分类能力与读取客户端：只允许固定类型及操作、精确白名单、响应大小限制、身份与字段授权、挂载/治理/ETL联动。
- [x] 向后安全白名单迁移；新增类型禁止继承CDC、写入与建表能力。
- [x] 前端分类、默认端口、目标命名、连接状态、驱动状态及能力说明；复用现有组件。
- [x] 协议、分页、上限、非法目标与权限检查；前端构建、Go检查和隔离集成。
- [x] 本机部署及数据保护核对；记录没有国产实例的验证边界。

当前会话直接实施，不使用子代理。集中进行有意义验证，避免重复红绿测试。


完成验证：Go 内部检查通过；前端相关43项检查通过（分组执行），构建通过；接口契约19项通过；隔离 PostgreSQL 上登记、挂载、权限、结构变化、治理剖析与实际 ETL 目标交付通过。接入服务真实 Redis/Doris 读取通过；ClickHouse/ES/HBase 采用协议夹具。四种国产官方驱动加载通过，国产库及 SQL Server、MongoDB 等未有真实实例联调，不能视为厂商版本兼容认证。
