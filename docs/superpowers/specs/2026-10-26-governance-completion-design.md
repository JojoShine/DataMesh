# 治理入口、模型与目录归属

按用户给定四项要求完成：补全子菜单图标；首页说明使用流程和常见治理工作流；完整运行选择根据结果生成模型时保存真实模型草稿；单表治理成果保留来源部门与原目录，并展示治理内容。

沿用现有 React/Ant Design、治理执行引擎、模型版本及目录挂载审批。模型从真实完整结果生成，属于待确认草稿；采样不生成正式模型，草稿不能冒充已发布契约。数据流和工作流子任务使用同一执行路径。

单来源成果记录来源资源、原部门、原目录和处理摘要。成果的提供部门为来源部门；运行仍属于原治理空间。申请人可在原目录选择原始或已审核启用的治理资源，各自使用自己的字段和挂载快照；不替换原资源，不继承原授权。

完成治理后的目录选择默认原目录，也可新建目录。复用共享交换的目录/挂载表单，审批、校验、启用保持有效。原目录允许可信治理衍生挂载与原始挂载并存，普通目录仍只允许一个主挂载，资源仍只能有一个启用挂载。

不新建平行引擎，不修改已确认字号，不放宽权限。增量 API 字段保持兼容；新索引迁移支持在存在衍生数据时安全拒绝回退。
