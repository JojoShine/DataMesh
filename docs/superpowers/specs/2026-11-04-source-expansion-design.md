# 数据源扩展范围

用户确认：保留 PostgreSQL/MySQL/Oracle，新增 SQL Server；国产仅达梦、金仓、瀚高、海量 Vastbase；分析型 Doris、ClickHouse；非关系型 MongoDB、Elasticsearch、Redis、HBase。不加入国产分布式数据库。暂无国产数据库联调实例。

首轮提供连接检查、对象发现、结构读取、样例、全量有界读取、目录挂载及现有 ETL/治理输入。新增类型不自动获得目标写入或 CDC 能力。已有三类数据库的读写、CDC 和凭据保持兼容。

Go 保持身份、精确目标白名单、凭据加密、目录审核和字段授权。新增只读 source-reader 隔离进程：SQL 使用 JDBC 元数据及构造的 SELECT，文档源使用标准客户端/REST。仅内网服务，必须使用共享服务凭据认证，不提供任意 SQL、驱动上传或公开端口。厂商 JDBC 驱动由部署管理员放入只读驱动目录，缺失时报告真实驱动状态，不能返回连接成功。

新增读取上限为10,000条/20MiB，超过时明确失败，不能把截断样本当作完整数据。MongoDB/ES/HBase 以稳定记录键和完整 JSON 文档映射到平台结构，Redis 增加值类型；保留嵌套及二进制内容。SQL 按真实字段、类型及主键；没有稳定主键时可读取治理，不能直接冒充稳定分页资源。

验证区分：协议与权限回归、开源真实实例、国产真实实例。当前缺少国产实例，最终说明此限制，不宣称厂商认证。
