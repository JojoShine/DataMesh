# 治理能力完善与新增

用户已批准六项：持续数据监测、标准落标、变更发布、主数据、指标口径、场景方案库。直接执行；不使用子代理，减少重复红绿测试。

沿用准备数据、处理数据、检查与交付、标准与规范、监控与追溯分类。复用空间、职责、固定版本、运行、数据流/工作流、整改与资产发布；不建立平行执行引擎。不将规则登记或模板展示宣称为真实计算，不代替人工合并核心业务实体。

持续监测：对授权资源进行周期完整剖析，记录行数、空值率、重复率和分布变化；更新时间从明确配置的业务时间字段取值，缺乏字段或有效值时显示无法核实。基线独立固定，变更有版本保护；权限撤销停止读取。定时、手动共用单并发入口，有实际报告与异常事件。

标准落标：展示可见模型/字段、已发布标准固定引用及覆盖率；扫描真实授权数据识别约束差异，建议映射需确认，已有标准和输出校验保持。

变更发布：复用版本差异/血缘，固定候选版本及试运行证据，保留独立审核和发布依据；恢复是引用旧版本，不覆盖历史或假装回滚源数据。

主数据：定义实体键、来源字段与匹配规则；对授权来源建立候选匹配、冲突清单，人工确认后生成版本；来源编号保留映射和操作记录。精确匹配为初期可解释基础，不能静默自动模糊合并。

指标：固定来源、维度、过滤、聚合和统计周期，复用数据流执行；口径发布有版本，结果与定义、运行、字段血缘联动。无任意SQL/代码公式执行。

场景方案：保存数据流/工作流固定版本及输入契约、验收说明，实例化时重新选择有权来源并做契约核验；不复制原凭据或授权。覆盖用户已有六类场景的方案编排能力，不制造业务运行结果。

统一边界：身份与空间隔离、字段授权、敏感值不出报告、不可覆盖已发布版本、明确完整/采样范围、分页15/20/25/50/100、既有字号和固定操作区。部署备份并核对原业务数据。
