# 数据服务与业务初始化

用户授权修复 SQL 数据服务创建，并将初始化升级为招生报名、人口库、法人库、死亡人口专项库、矛盾调解、不动产六个场景。直接执行，不使用子代理，集中验证。

## 数据服务
已有默认字段查询校验通过；核对普通 SQL 写法及缺少匹配 API 目录时的创建路径。保持单成果只读、参数绑定、敏感字段保护、目录审核和使用授权，不开放任意数据库 SQL。用户进一步确认：一份业务目录下支持库表与 API 不同呈现，不再创建重复 API 目录。生成服务绑定原已审核来源挂载，只允许已共享字段的子集；接口独立审核和使用授权，来源暂停或版本变化时阻断接口。既有独立 API 目录保持兼容。精确用户报错 SQL 已异步询问，继续独立工作。

## 初始化
- 业务名称、字段和值采用自然业务表达，无 test/demo/模拟姓名等前缀。生成虚构业务记录，不使用真实自然人敏感资料；来源性质和生成版本记录在初始化清单及文档，不伪称真实政务记录。
- 保留既有 enrollment 七表结构，以新业务记录升级已确认的旧初始化内容。新建人口、法人、死亡人口、调解及不动产关联表，每表 1,000–10,000 行，使用稳定业务主键及一致跨场景关系。
- 每场景登记来源目录与资源，准备治理空间、关联流程和已核验资产，首页可见六类资产；实际记录继续受控访问。准备一个 SQL 数据服务完成真实创建验证。
- 幂等初始化：固定版本、确定性生成、源表内容摘要、进度清单、API 幂等键和备份。只升级本脚本管理的内容；未知同名表或人工修改时拒绝覆盖。已有测试字典及编码不冒充正式规则，新业务目录使用独立已核验的内部编码字典。
- 旧初始化目录/资产按既有撤回或退役流程退出在用展示，保留审计、授权及不可变运行证据，不批量删除业务表。存量业务源连接不更改连接配置。
- 提供可迁移初始化包及新机器执行入口，数据库结构迁移与业务初始化分别版本化；迁移复制实际业务数据使用备份，干净环境可重建相同基础业务记录。

验收：各表规模、主键唯一、类型、关系、日期金额范围与无测试前缀；两次执行幂等；六个真实治理运行、血缘、公开元信息与受控记录；SQL 校验/目录/登记/挂载流程；既有用户、权限和非初始化数据保留。

实施裁定：按用户后续明确要求替换“新建匹配 API 目录”的临时实现；新增 service_variant 由服务端验证可信来源，不接受客户端声明；迁移41允许经核验查询服务与原主挂载并存，并修正初始化登记表就绪检查所需 SELECT 权限。
