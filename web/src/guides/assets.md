# 数据资产操作指南

数据资产帮助你找到已共享的数据，判断是否适用，申请并使用。治理平台负责处理与核验，共享交换负责编目、审核和授权；三个平台共用同一份资源与授权记录。

## 开始之前与职责

登录后进入数据资产。普通使用者主要办理发现、申请、使用、关注与反馈；提交使用申请仍需数据使用角色。产品维护视图面向具有提供、治理或管理员角色且对相应产品有维护权限的账号；审核仍需独立的有权审核人。

如果页面没有维护或审核按钮，先确认账号角色、平台入口和资源职责。不要通过新建重复产品或反复申请绕过权限限制；由管理员在[账号管理](/platform/security/accounts)和[资源权限](/platform/security/resource-access)核对。安全平台的分级、策略和冻结会继续约束实际使用。

## 从来源到首页展示

1. 提供方在共享交换[数据源管理](/platform/exchange/sources)登记来源，在[资源目录](/platform/exchange/directory)编目并挂载原始表、文件或接口。
2. 需要加工时，治理人员在[来源数据](/platform/governance/space-sources)关联有权使用的资源，在[数据流设计](/platform/governance/dataflows)执行清洗、质量检查或关联。
3. 在[成果核验](/platform/governance/results)查看本次实际结果、质量、来源和模型证据；满足条件后发布成果。仅保存数据流、运行成功或发布成果都不等于已经共享。
4. 有职责的提供方继续在共享交换编目或关联成果，完成目录与挂载审核并启用共享。具体过程见[共享交换操作指南](/guides/exchange)。
5. 使用者回到资产发现，选择具体原始资源或治理成果申请使用。首页只展示已满足公开摘要条件的治理成果；提供方还需明确允许公开，实际记录继续受授权和安全检查约束。

## 功能分类与资产总览

左侧按“资产工作台、发现与理解、申请与使用、关注与反馈”分组。原有页面和授权流程保留。

入口：[资产总览](/platform/assets/overview)。查看当前账号可见的共享目录总数、本人申请、授权记录和使用反馈。统计使用接口返回的总数；授权记录包含历史记录，不代表全部仍有效。接口失败时显示错误并可重试。

入口：[分类浏览](/platform/assets/categories)。按基础信息、主题信息、部门信息查看已发布目录数量并进入对应分类。进入后继续搜索，分类筛选作用于完整目录查询。

入口：[可信资产核验](/platform/assets/trust)。选择共享资源后直接核对该版本的字段、责任人、质量与更新证据。未提供的证据显示未知或未提供，不据此推定资产已认证。

## 发现可用资产

入口：[资产发现](/platform/assets/catalog)。

按名称、资源编码或分类查找。点击资产名称或“查看与申请”，了解提供单位、业务说明、更新周期、共享条件和数据字段。目录内可以包含原始数据与治理成果，需分别选择与申请。交付方式包括查询数据、下载文件和调用 API。

这里只展示已完成审核并启用共享挂载的目录，不包含尚未共享的内部资产，也不会自动收录私人轻量治理文件。资源状态变化时可能暂不可用；重新刷新核对。

## 判断是否适用

先看业务说明、字段、版本和使用限制，再看治理内容与质量结论。未提供质量检查结论不能理解为已通过检查。“字段、质量与更新”列出审核后的字段口径、责任人和实际运行证据。输出格式校验仅表示满足绑定模型；业务质量结论只覆盖当次配置的检查规则。

当前成果生成时间、上游最近运行和成果文件归档时间分别展示。较新的上游运行不代表这份共享版本已替换，文件归档也不代表数据实时。缺少可靠记录的数据截止时间显示未知；更新周期是提供部门声明，不能作为运行成功的证明。

选择治理成果时，可查看已有的来源及处理说明。没有记录的证据会明确提示，不推测处理质量。需要不同范围或交付方式时，联系提供部门共享对应资源。

## 申请使用

在详情选择数据，点击“申请使用所选数据”。填写用途、依据、使用场景、范围、部门同意记录与期限，并选择所需字段；文件按完整文件申请。敏感字段按批准策略脱敏。

申请由共享交换的资源负责人审批。仅开通资产平台的使用者也可申请，无须拥有目录管理权限；账号仍需具备数据使用角色。

## 跟踪申请

入口：[我的申请](/platform/assets/applications)。

这里仅显示本人申请。查看状态与处理意见，需要补正时完善材料后提交；不再需要的待审申请可撤回。审批通过会生成同一资源的使用授权，不需要再次申请。

## 使用已授权资产

入口：[我的资产](/platform/assets/grants)。

根据授权交付方式点击“查询数据”“下载文件”或“调用 API”。查询仅返回获批字段；API 需按页面要求填写参数。平台生成的数据服务可在调用窗口创建、查看和撤销本人的调用凭据，供外部系统访问。

凭据仅在创建时显示一次，请及时妥善保存。有效期不会超过原授权，原授权撤销、资源停用或账号状态变化后，调用仍会被拒绝。普通外部 API 代理暂不提供这种平台生成凭据入口。

## 不可用时如何处理

授权过期或被撤销：返回资产发现核对资源并重新申请。

目录下架、共享暂停或版本变化：联系提供部门确认；即使授权列表仍保留历史记录，也不能绕过当前共享校验继续使用。

找不到资产：确认提供部门已完成目录审核、资源挂载及共享启用。仅在治理平台完成处理或发布，不代表已经开放共享。

## 反馈使用问题

在资产详情选择“反馈使用问题”，或在“我的资产”的授权记录旁点击“反馈问题”。可反馈数据质量、更新、字段口径和访问交付问题，填写涉及字段、具体情况与期望结果，不填写敏感记录原值、密码或令牌。

反馈保留提交时的资源版本；已有本人授权记录即使过期或共享暂停，仍可从该记录反馈访问问题。在[我的反馈](/platform/assets/feedback)查看公开回复与处理进度，其他使用者无法看到。

治理人员在质量管理的“使用反馈”受理。关联到治理整改的问题必须完成真实复测并关闭整改单后才能完成反馈；不涉及治理运行的口径、访问问题可以直接核实回复。反馈不会自动执行治理或发布新成果。内部运行日志和整改笔记不向使用者展示。

## 收藏与关注

在资产详情点击“收藏资产”方便再次查找，点击“关注变化”关注该资源版本的共享状态。两项可独立开关，不会产生授权或自动提交申请。

入口：[收藏与关注](/platform/assets/saved)，分别查看“我的收藏”“我的关注”。点击“核对共享状态”刷新状态；暂停或下架的资产保留您曾见的名称，仍可取消收藏或关注。当前每人最多保留 100 份收藏或关注，可整理不再使用的资产。

## 查看站内提醒

入口：[我的提醒](/platform/assets/notices)。进入页面或点击“核对最新状态”时检查关注资产的共享变化，以及本人授权在 7 天内到期或已经到期的情况。可筛选未读、标记已读，并返回资产核对或查看授权。

共享目录、挂载依据变化、暂不可用和恢复共享会生成站内提醒。同一观察状态不会因重复刷新反复提醒。取消关注后停止生成对应的共享变化提醒，历史提醒保留。授权到期提醒根据本人授权生成，不依赖收藏或关注。

本功能不是后台实时推送，不发送邮件；两次核对之间发生又恢复的短暂变化可能不会记录。提醒时间是发现时间，不是源数据更新时间，也不是完整变更审计。重新申请仍须审批，不会自动续期；提醒中的历史状态以最新核对和实际使用校验为准。

## 数据产品

在“发现与理解 → 数据产品”搜索已发布产品，核对业务说明、主题域、术语、固定共享资源版本、发布字段快照、使用限制和契约。每个资源仍需按原流程申请授权；产品发布或认证不会授予访问权限。

提供者、治理者或管理员可以切换“维护视图”，新建产品或维护本人有权限的产品。填写名称、说明，从已共享目录中搜索、分页选择1至10项资源；主题域和术语只从有权限读取的已发布治理定义中远程选择。新鲜度以秒计，0表示未约定；最大隔离记录比例在0至1之间，留空表示未约定。保存草稿后填写原因并提交审核。草稿变更不会替换消费者看到的旧发布版。

有实际审核权限且与产品负责人不同的审核人可批准或退回。批准时必须填写未来366天内的认证到期时间。发布时后台重新核对资源和业务语义，版本冲突或资源不可用时按返回提示修正后重试。

### 维护和审核步骤

1. 打开数据产品，切换“维护视图”，点击“新建产品”；已有产品从名称进入后选择“编辑定义”。
2. 填写产品名称、说明、共享资源、可选主题域和术语、契约及使用限制，点击“保存草稿”。先确认每项资源的版本与字段范围，再提交。
3. 打开草稿，点击“提交审核”，填写操作原因并确认。由另一位有权限的审核人核对资源、语义、限制和认证期限，选择“批准发布”或“退回修改”。
4. 退回后由维护人修改再提交；发布后的修改先保留为维护版本，消费者继续看到原发布版，直至新版通过审核。
5. 使用者打开发布产品，逐项进入共享资源申请使用。发现产品并不代表所有成员资源都已有授权。

## 契约核验与本人记录

进入“发现与理解 → 契约核验”，打开产品，点击“核验发布契约”。检查使用发布版，包括共享版本可用性、字段兼容性、新鲜度和实际隔离比例。缺少证据显示“未知”，不能视为通过；已观察到违约优先显示“违约”。页面只在主动核验时生成结果，不提供后台实时推送。

看到“违约”时，展开逐资源检查项，确认是版本不可用、字段变化、更新超期还是隔离比例超出约定，再联系产品维护人或通过相应资源提交反馈。看到“未知”时，先补齐证据或约定，不把它当成通过。

下方记录只属于本人，可展开查看逐资源检查信息，并按页回看历史及违约记录。核验发现违约时会生成个人站内提醒；同一发布版、相同检查结果不会重复生成提醒。提醒可直接返回对应产品核验。本页刷新提醒不会自动执行产品契约检查。

## 认证与生命周期

在“资产工作台 → 认证与生命周期”查看人工认证状态和到期时间。人工限期审查不表示全部业务质量通过。维护视图内按实际权限编辑、提交和审核产品；已发布产品可填写原因弃用，可选另一已发布产品作为替代。弃用不撤销原资源授权。已弃用产品可进一步停用，停用后消费者不能再发现此产品。

办理时先确认需要修改定义、弃用还是停用：定义更新走草稿和审核；不再推荐使用时打开已发布产品，点击“弃用产品”，填写原因及可选替代产品；确认结束展示后，对已弃用产品点击“停用产品”。产品生命周期不代替资源目录下架或使用授权撤销，这些分别由原流程办理。

## 我的使用统计

在“申请与使用 → 我的使用统计”选择最近7、30或90天，查看本人成功交付次数、按操作和UTC日期的汇总。时间区间以UTC明确展示。次数不是数据行数、字节数或使用人数；没有可核实的费用、成本和业务价值数据时不推算金额或收益。

## 用演示资产走一遍

当前本地实例已准备两张虚构来源表和两项已共享成果。在[首页](/)或资产发现搜索“演示”，从以下两项开始检查。

| 演示资产 | 来源与处理 | 应看到的结果 |
| --- | --- | --- |
| 演示·客户档案（单表质量处理） | 8条客户记录，去除名称和城市首尾空格，检查名称必填、长度及年龄范围 | 6条合格客户；2条问题记录保留隔离处理证据 |
| 演示·客户订单明细（双表关联） | 合格客户与10条订单按客户编号关联 | 10条带客户名称、城市和金额的订单明细，可追溯到两张来源表 |

1. 在首页点击“查看详情”核对说明，再登录进入目录申请使用；首页不会直接显示业务记录。
2. 在资产发现打开对应目录，选择治理成果，查看“字段、质量与更新”及来源处理说明。
3. 普通使用者按申请流程办理，在“我的申请”跟踪；有有效授权后，从“我的资产”查询结果。管理员的既有管理权限不会自动生成一份本人使用申请。
4. 如需检查处理配置，在治理平台选择“演示资产：单表质量与双表关联”空间，查看数据流及成果核验。演示数据均为虚构；样例未自动替你发布安全策略或水印模板。

## 与数据安全联动

在资产或产品成员资源详情核对安全级别、保护要求、冻结状态和交付凭据。资源负责人可从详情进入安全标签维护；新增或修改标签仍须由独立的有权人员复核。

使用已授权资产时，后台仍会检查当前策略。查询可能显示可见水印或脱敏，文件交付按支持格式生成标记，API可能带交付编号；具体能力见[数据安全操作指南](/guides/security)。遇到冻结、格式不支持或验证失败，记录资源版本、操作和追踪号，联系管理员核对；不要把敏感原值写入反馈。
