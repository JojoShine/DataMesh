# 数据治理三页交互稿

本地预览：http://127.0.0.1:15173/governance-prototype.html

本稿用于评审治理工作台、数据流设计、成果核验的交互。沿用平台主题、单层 GovernanceDialog 和数据流图组件；没有修改主环境页面、接口、权限或数据。其他功能以办理关系说明衔接，完整功能关系方案保留在 `docs/design/governance-function-map-and-onboarding-v1.md`。

## 查看顺序

1. 初次进入选择“开始虚线框学习”，依次学习工作台 4 步、数据流 5 步、成果核验 4 步。学习副本的修改与操作副本隔离。可暂停，也可从每页重新学习。
2. 工作台查看目标、来源—模型—处理—运行—核验—共享的关系，以及主题域、责任、术语、标准的必要性。点击事项继续操作。
3. 数据流点选节点配置；通过页签分别查看前置条件、版本影响、运行证据。保存草稿→核对并发布定义→确认版本及迁移安排→完整运行→前往成果核验。
4. 成果核验查看固定版本及六项条件，核验并发布后查看目录、挂接、审核、申请和授权的后续关系。

## 可点通的示例场景

在数据流或成果列表右侧切换“演示场景”，每次切换都会重置本稿中的演示状态。

| 场景 | 观察重点 | 继续办理 |
| --- | --- | --- |
| 条件满足 | 新草稿与历史运行各有版本；定义发布不等于运行完成 | 保存、发布定义、完整运行、核验成果、发布、查看共享后续 |
| 质量异常 | 20 条隔离记录，0 个成功成果；发布不可用 | 查看原因→示例来源整改完成→按原 v2 完整复测→查看新成果；历史失败证据继续保留 |
| 来源变更 | 当前契约 v2，旧运行引用 v1；旧成果不能直接发布 | 核对并采用新示例契约→保存修订定义→发布→完整运行→核验新成果 |

来源结构、模型、标准、术语、工作流、调度、质量整改、血缘、生命周期和共享均可查看“为什么需要、什么时候用、前置、后续、必选/可选”。关联说明替换当前 Dialog 内容，返回时恢复原位置；没有叠加第二层弹窗。

全部提交、添加、移除和返回操作位于 Dialog 右下方。正文仅保留页签、节点选择、配置字段及查看关联说明的链接。

## 演示边界

- 全部资源、权限、运行和发布均为内存中的预设示例；不调用业务接口。演示运行的 1000 行及异常计数不由数据库或算子计算产生。
- 10 类算子入口保留；本稿重点演示已有四节点清洗流程。多表关联、跨表检查及复杂算子配置需要在完整业务功能办理，不能以本稿代替服务端执行验证。
- 历史证据在当前演示场景内保留；刷新页面重置操作状态和本轮学习进度。
- 主环境未部署。生产构建只包含既有入口，本稿通过独立开发入口预览。
