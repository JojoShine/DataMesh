# 组件适配契约

业务模块依赖适配器接口，不直接散布外部组件 SDK。后台控制任务与 Flink 数据处理作业分开。

| 操作 | 输入 | 输出与约束 |
| --- | --- | --- |
| Submit | operation_id、task_id、run_id、不可变配置版本 | external_job_id、accepted/running/failed/unknown；同一操作号不得创建两个作业 |
| Query | operation_id 或 external_job_id | 实际组件状态、位点、检查点、错误、观察时间；查询失败不等于作业不存在 |
| Pause / Resume | operation_id、运行标识及期望配置版本 | 操作状态；结果未知先 Query 再重试 |
| Replay | 新 operation_id、原始对象、源序列作用域、明确截止范围及原因 | 独立运行；保留原始顺序，不覆盖更新版本或复活已删除记录 |
| QueryResult | 治理数据集版本、允许字段、白名单筛选、分页边界 | 有界结果；禁止传任意 SQL、表名或表达式 |
| QueryRaw | 原始对象版本、授权范围、截止水位、分页游标 | 含来源、模式、操作、键和位点上下文的事件；游标与授权范围绑定 |
| ArchiveManifest | 来源对象、Kafka 分区 offset 范围、源位点映射 | 文件位置、SHA-256、数量和完成状态；不能用文件存在代替事件范围完整 |
| Reconcile | 可对齐的截止点及清单 | 源、处理、Doris 与归档差异；持续变化的总行数不直接比较 |

外部失败区分 unavailable、invalid_config、permission_denied、position_expired、incompatible_schema、target_failed 和 unknown。禁止将异常转换为空成功结果。可重试错误有限退避；超时未必意味着操作失败。

逻辑事件见 JSON Schema；Debezium 原生封套中的 before/after、op、source、transaction 和 snapshot 上下文必须保存。PostgreSQL 的 LSN、MySQL 的 binlog 文件/位置/行序号、Oracle 的 SCN/事务内顺序各有作用域，不能比较裸字符串或跨源时间戳。具体映射以连接器精确版本的真实样例冻结，本批烟测不能证明全部重放语义。

## 资源挂载（2026-10-16）

入口为「共享交换 → 目录注册 → 目录行的挂载资源」。新接入先生成不可变资源，再保存挂载草稿；实际校验、审核及启用后才允许申请。新版本通过新资源引用和挂载修订替换，旧授权不自动转移。

| 载体 | 接入与使用 | 当前边界 |
| --- | --- | --- |
| 库表 | PostgreSQL/MySQL 选表、字段映射、真实查询 | 直接查询独立于 CDC；启用共享需要主键，结构变化阻止交付；Oracle 保留现有采集链路 |
| Excel 数据 | 上传 XLSX、选择工作表和表头行、匹配目录字段、完整校验后原子导入 | 不导入数据项定义；20 MiB / 100 列 / 5 万行，解压及解析数据各限 64 MiB；长整数和小数使用文本保精度 |
| 文件 | 上传、生成固定版本、审核后完整附件下载 | PDF/TXT/CSV/DOCX/XLSX/PPTX，50 MiB；私有存储和 SHA-256 校验，不能用字段查询授权替代下载授权 |
| API | GET / 只读 POST、参数定义、响应路径映射、实际测试及受控调用 | JSON 对象/对象数组，8 秒、2 MiB、每账号/资源每分钟 60 次；无授权不调用上游 |

Excel 导入沿用目录结构，必填列缺失、映射歧义、错误值或公式均阻止确认；额外列不导入。导入批次确认按配置摘要幂等，重复确认不生成重复数据；页面「查询导入状态」用于超时后核对。处理中失败事务回滚，批次可重试。未确认批次 24 小时失效，在后续上传时分批回收；已确认版本不被回收。文件处理单实例串行限流，繁忙返回 429；本地服务内存上限调整为 512 MiB。容量上限是输入边界，不代表已经完成最大容量压测。

治理成果的库表入口仍选择资产平台已发布的数据集，保留既有质量门禁和版本约束；不会把 Excel 上传当成已经完成治理。新文件/API 的数据层由目录声明，不等同于资产平台质量认证。

数据库新增目标使用 `SOURCE_ALLOWED_TARGETS` JSON 数组配置，元素为 `kind/host/port/database`；原有本地样例继续可用。当前连接配置面向本地 Docker 环境。API 使用 `API_ALLOWED_TARGETS` 数组，元素为 `origin/addresses`，精确限定源站和解析地址；HTTP 仅允许内网或回环地址，其余使用 HTTPS，重定向拒绝，密钥加密保存且不返回前端。配置后需重建本地 server 容器才能生效。API 请求参数以文本输入，按声明类型校验；只允许登记时固定的目标和鉴权配置。

普通用户每次交付均核验账号、部门、字段、期限、交付方式及有效目录/挂载修订。库表/API 对源和目录两者的敏感标记取更严格者；文件按完整版本授权，无法逐字段脱敏。管理员保留已约定的业务权限。审计不记录完整文件内容、接口密钥或响应数据。
