Source: NotoSansSC[wght].ttf (downloaded 2026-11-11).

The source variable font was instantiated at wght=500 using fontTools 4.68.0
(fontTools.varLib.instancer.instantiateVariableFont). All original glyphs
are retained. This avoids the variable font's very thin default weight when
rendering with golang.org/x/image. The font is compiled into the server;
watermark text is rasterized and the resulting glyph image is embedded in
PDF page content. Unsupported glyphs cause delivery to fail closed.
